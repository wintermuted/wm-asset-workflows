# Wintermuted UI Theme

## Authoring

Use the `/create-svg-asset` Copilot Chat prompt with:

```text
Project: Wintermuted UI Theme
Directory: assets/svg/wintermuted-ui-theme/
```

Add reference images to `assets/svg/wintermuted-ui-theme/grounding/`. Register finished SVGs in `manifests/assets.json`.
