# Solar Punk

## Authoring

Use the `/create-svg-asset` Copilot Chat prompt with:

```text
Project: Solar Punk
Directory: assets/svg/solar-punk/
```

Add reference images to `assets/svg/solar-punk/grounding/`. Register finished SVGs in `manifests/assets.json`.
